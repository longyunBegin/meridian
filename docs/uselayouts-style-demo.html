useLayouts，按我的理解

不是一套花哨皮肤，而是四条可执行的规则：层级靠留白与字阶，颜色只表语义，层次靠发丝线与柔和阴影，动效短、跟手、可关闭。下面这块可点的小工作台，就是这些规则叠在一起的样子。

1. 读得懂优先字阶与留白建层级，不加粗边框堆盒子。
2. 颜色有语义蓝强调、绿佐证、红反对；不做装饰渐变。
3. 质感克制细边 + `--sh-1/2/3`；列表不抬，卡片才抬。
4. 动效有目的入场 rise、数字 pop、选中条滑入；常态不动。

我认为「是」

  • 发丝线 + 柔和多层阴影，不靠粗框
  • 列表不跳、卡片才抬
  • 选中 = 左侧细色条滑入，不是整圈霓虹
  • 入场 stagger，数字变化轻 pop
  • 语义色克制；字重最多到 600
  • `prefers-reduced-motion` 一刀切掉动画

我认为「不是」

  • 紫靛渐变、黑重投影、玻璃霜乱洒
  • 每行都抬升、到处 glow
  • 选中描一圈蓝光 / 胶囊贴纸堆叠
  • 常态循环动画、滚动数字表演
  • 另起一套私有蓝边蓝底（demo 皮肤）
