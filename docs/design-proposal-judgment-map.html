相对现状改了什么、为什么

  • 01x/y 位置改为表达数据。现状是向日葵螺旋，点在簇内的位置不带任何信息；现在横轴 = 独立来源档位，纵轴 = 强度，位置本身就是结论。
  • 02分类从"大圆面积"降级为"颜色 + 筛选"。分类只是名称，不需要占画布七成的面积；未分类不再是画面上最大的圆，而是一行可点的提示。
  • 03证据状况不丢。没有来源 ⇔ 第 1 列；单一来源 ⇔ 第 2 列；多来源一致 ⇔ 第 3/4 列且无红环；有争议 ⇔ 红环（必然 ≥1 条已表态来源）。可以从位置 + 外环完整推回去。
  • 04两条分界线都沿用现有口径。竖线 = claimStateOf 的「多来源一致」（sources ≥ 2）；横线 = 新观点默认强度 50（domain-commands.js），严格大于 50 才算"强"。
  • 05"没记录"不再画成"弱"。强度为 null 的观点放进底部带子，横向仍按来源档位对齐；不会出现在 0 上（避开 Number(null) === 0）。
  • 06标题常显 + 确定性避让（右 → 左 → 下 → 上，放不下才收进悬浮）；≤40 条全部尝试，超过只给前 14 条优先级最高的（选中 → 有争议 → 强但证据薄 → 强度高）。
  • 07关系线默认不画，悬浮/选中某点才画它自己的边并压暗其余点，避免现状那种跨簇的长淡线。
  • 08现状图例里的字面 **…** 是把 Markdown 当纯文本输出的 bug，改成可视化图例后自然消失。
