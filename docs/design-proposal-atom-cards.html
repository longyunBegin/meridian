最值得先看的 5 条

  • 01缩略图：小、常驻、无标签、只画点与簇（可选画簇内细线）。全图在 1000 节点时是一团毛线，缩到 196px 高反而能读出密度与分簇。
  • 02分簇必须可解释：默认按主题自定义分类；另一档按证据状况（没有来源 / 单一来源 / 有争议 / 多来源一致）——两档读者都能自己讲明白，不用社区发现算法。
  • 03Top 5 必须写清排序依据（右上角 + 每张卡的徽标），否则读者会默认它是"最重要"。四档：来源最多 / 争议最大 / 最缺证据 / 最近变化。
  • 04原子太少时缩略图自动隐藏（< 12 条退成一行摘要）——现在 dev 数据只有 9 条观点，硬画缩略图没有信息量。
  • 05展开＝图的局部替代：点「展开」在卡下直接列支持/反驳来源与相邻观点，比"点节点看侧栏"少一次滚动。
  • 06对比度已按评估修：说明文字 .55（浅色 4.6:1）、语义色文字用深色变体（绿 5.4:1 / 橙 5.6:1 / 红 5.4:1）。
